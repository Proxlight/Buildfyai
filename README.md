 # Buildfy AI: AI-Powered Python GUI Builder

## Overview
Buildfy AI is a desktop application that lets you generate and edit Python GUIs using natural language prompts. Powered by Gemini AI and built with [customtkinter](https://github.com/TomSchimansky/CustomTkinter), it enables rapid prototyping and interactive editing of Python desktop apps—no manual coding required.

## Features
- Prompt-based GUI generation using Gemini AI
- Real-time, interactive preview of generated UIs (not just images)
- Live code editor with instant preview
- Chat-style prompt history and version rollback
- Trial mode: 3 free generations per month
- Buy full version for unlimited generations

## What’s New
- **Export functionality removed:** You can preview and edit GUIs, but code export is only available in the full version.
- **Trial Mode:** Click the "Trial Mode" button to activate 3 free generations/month without a license key.

## Setup
1. **Clone this repository:**
   ```bash
   git clone https://github.com/Proxlight/buildfyai.git
   cd buildfyai
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the app:**
   ```bash
   python Buildfy\ AI.py
   ```

## Usage
- Enter a prompt like `Create a login form with two input fields and a login button.`
- See the generated GUI and code update live.
- Edit code directly or use follow-up prompts to modify the UI.
- Click "Trial Mode" for 3 free generations/month, or purchase the full version for unlimited generations.
